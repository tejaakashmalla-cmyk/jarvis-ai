# Python Calculator

## Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division.

## Setup Instructions

1. Ensure you have Python installed on your system. You can download it from the official Python website: https://www.python.org/downloads/
2. Clone or download this repository to your local machine.
3. Navigate to the directory containing `src/main.py`.
4. Run the script using a Python interpreter:
   ```
   python src/main.py
   ```

## Requirements

- This project has no external dependencies as it is self-contained and uses only Python's built-in features.
